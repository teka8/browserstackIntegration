You are a Senior QA Architect and .NET Automation Expert.

I want you to design and generate a complete, production-ready Playwright .NET test automation framework for BOTH UI and API testing, following industry best practices.

Context:
- Language: C# (.NET)
- Framework: Microsoft Playwright for .NET
- Test Runner: NUnit
- Target: Web UI + REST API testing in the same solution
- Environment support: local, Dev, staging, production
- CI/CD ready (GitHub Actions or Azure DevOps)

Requirements:
1. Solution Structure
   - Clean folder structure (UI, API, Core, Utils, Config, Fixtures)
   - Clear separation of concerns
   - Reusable components and helpers

2. UI Automation
   - Page Object Model (POM) or Screenplay (recommend best approach)
   - Stable locators strategy
   - Parallel execution
   - Cross-browser support (Chromium, Firefox, WebKit)
   - Proper waits and async handling
   - Screenshot + video on failure

3. API Automation
   - API client abstraction
   - Auth handling (token-based)
   - Request/response validation
   - Schema validation
   - Reusable API helpers

4. Configuration & Environment Management
   - appsettings.json + environment overrides
   - Secure secrets handling
   - Base URLs per environment

5. Test Data Management
   - Test data builders or factories
   - Randomized data where applicable
   - Cleanup strategy

6. Reporting & Logging
   - HTML report integration (Allure or Playwright HTML)
   - Structured logging
   - Failure diagnostics

7. CI/CD
   - Sample pipeline config
   - Headless execution
   - Artifact publishing (reports, screenshots)

8. Best Practices
   - Naming conventions
   - Async/await usage
   - Retry strategy (when appropriate)
   - Tagging tests (smoke, regression)
   - Code examples with explanations

Assume this framework will be used by a mid-to-large team and must be maintainable long-term.
